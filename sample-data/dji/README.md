# Dummy DJI flight logs

Generated by `npm run fdr:dummy` (`fdr-parser/tools/generate-dummy-dji.js`) so the system can be
built and demonstrated before a real drone is available. Running the generator again produces the
same files (seeded random numbers).

| File | Scenario |
| --- | --- |
| `DJIFlightRecord_2025-05-18_[16-00-00]_52xx.txt` (6 files) | 6 drones flying a V-formation loop around Langkawi airport (group "LIMA 2025") |
| `DJIFlightRecord_2025-09-23_[10-00-00]_5203.txt` | Orbits and a figure of eight at Subang |
| `DJIFlightRecord_2025-11-25_[08-00-00]_5210.txt` | Lawnmower survey pattern at Gong Kedak |

Each flight: motors on → auto take-off → climb to ~120 m → waypoint mission → return home → auto landing,
logged at 5 Hz (real DJI logs are 10 Hz).

**Format:** these are text files in the *decoded* DJI flight-record CSV layout (`OSD.latitude`,
`OSD.height [ft]`, `OSD.hSpeed [MPH]`, `BATTERY.chargeLevel`, …). A real `DJIFlightRecord_*.txt` straight
from the DJI app is binary and encrypted; see `fdr-parser/README.md` for how those are handled.

Upload any of these on **Flights → Add Flight → FDR file** to test the pipeline.
